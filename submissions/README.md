# Submissions / 提交資料

Use this folder for final or near-final submission drafts.

本目錄用於保存最終提交或接近最終版本的提交草稿。

## Submission Checklist / 提交檢查清單

- [ ] Requirement is understood.
- [ ] Output link is correct.
- [ ] Evidence is public if required.
- [ ] No private data is included.
- [ ] README or note explains the context.
- [ ] Bilingual summary is ready if useful.
