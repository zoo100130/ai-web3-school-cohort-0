## Idea 1: AI x Web3 Beginner Learning Companion

中文：

一個幫助 AI x Web3 新手完成每日學習的工具：讀取任務、生成每日打卡草稿、提醒隱私檢查、整理 GitHub 證明、沉淀 Handbook feedback。

English:

A tool for AI x Web3 beginners that helps read tasks, draft daily check-ins, remind privacy checks, organize GitHub evidence, and collect Handbook feedback.

### Target User / 目標使用者

- Beginner learners in AI x Web3 School
- Students who are new to GitHub
- Hackathon participants who need a clear output trail

### Problem / 問題

Beginners struggle with fragmented workflows: course task, notes, proof, feedback, and submission are spread across different places.

新手的學習流程容易分散：課程任務、筆記、證明、回饋和提交分布在不同地方。

### Smallest Demo / 最小演示

- Input: daily task text
- Output: bilingual daily note, task checklist, privacy checklist, GitHub commit message suggestion

### Open Questions / 待確認問題

- Can the tool connect to WCB task data, or should it stay as a manual assistant?
- What proof format does the course prefer?
- Which parts should remain local for privacy?
