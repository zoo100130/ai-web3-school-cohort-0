# Week 1 Agent Workflow Demo

Concept / 概念：LLM / workflow / agent

This is an interactive Week 1 learning artifact. It explains how an AI agent turns a learner's goal into a safe, reviewable workflow.

這是一個 Week 1 互動學習產物，用來理解 AI agent 如何把學習者目標拆成可檢查、可確認、可執行的 workflow。

## Files / 檔案

- `index.html`: interactive page
- `styles.css`: visual design
- `script.js`: step switching, mini demo, and quiz logic

## How to Use / 使用方式

Open `index.html` in a browser.

可以直接用瀏覽器開啟 `index.html`。

## Learning Goal / 學習目標

- Understand the difference between LLM, workflow, and agent.
- See why human confirmation matters before public actions.
- Practice identifying safe vs risky agent behavior.

## Privacy / 隱私

This demo does not use API keys, wallets, private accounts, or external services.
