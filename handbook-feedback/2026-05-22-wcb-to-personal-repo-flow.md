## What Confused Me / 我困惑的地方

中文：

新手可能會分不清楚三件事：WCB 共學筆記、個人 GitHub daily note、以及平台提交連結。這些看起來都像「學習紀錄」，但用途和更新位置不同。

English:

Beginners may confuse WCB co-learning notes, personal GitHub daily notes, and platform submission links. They all look like learning records, but they have different purposes and update locations.

## Suggested Improvement / 修改建議

中文：

建議 Handbook 加入一張簡單流程圖，說明：WCB 任務 -> WCB `notes/username.md` -> 個人 repo `daily/` -> task proof / submission link -> Handbook feedback。

English:

Add a simple flow diagram: WCB task -> WCB `notes/username.md` -> personal repo `daily/` -> task proof / submission link -> Handbook feedback.

## Why It Helps Beginners / 為什麼對新手有幫助

中文：

這可以降低新手對「到底要更新哪裡」的焦慮，也能避免把敏感資訊或錯誤連結提交到公開 repo。

English:

This reduces beginner anxiety about where to update things and helps avoid publishing sensitive information or wrong links.
